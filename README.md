## Git Commands Used
During the development of the project, we used Git and GitHub for version control and collaboration:
-git clone: Used to copy the project repository to our local computer. 

-git checkout: Used to switch between branches or create a new branch. 

-git fetch: Used to retrieve the latest changes from the remote repository without merging them. 

-git pull: Used to download and merge the latest changes from GitHub into the local project. 

-git commit: Used to save our changes to the local Git history with a meaningful message. 

-git push: Used to upload our committed changes to GitHub. 

-git merge: Used to combine changes from one branch into another. 

We followed a GitHub Flow approach where changes were developed on separate branches, reviewed, and then merged into the main branch.
